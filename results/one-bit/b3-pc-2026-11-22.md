# B3 on the PC: Bonsai 4B and 8B Q1_0

aether-infer `one-bit` `0e071bb` (no code change in this step), llama.cpp
`d02b4c0d6` (CPU build). Host i7-13620H, 12 threads, plugged in. Files:
`prism-ml/Bonsai-4B-gguf` `Bonsai-4B-Q1_0.gguf` (572,270,624 bytes) and
`prism-ml/Bonsai-8B-gguf` `Bonsai-8B-Q1_0.gguf` (1,158,654,496 bytes).
These are correctness and host-side checks; **the phone measurements that
B3 is for are still owed** (the phone was not reachable in this session).

## What the files are

Both are `qwen3`, 36 layers, 32 q heads / 8 kv heads, head dim 128,
vocab 151,669, and every matrix is Q1_0. They differ from the 1.7B in
more than size:

| | 4B | 8B |
| --- | --- | --- |
| hidden / FFN | 2560 / 9728 | 4096 / 12288 |
| context (file) | 32768 | 65536 |
| YaRN | factor 4, original 8192 | factor 4, original 16384 |
| rope theta | 5,000,000 | 1,000,000 |
| classifier | tied (398 tensors: 253 Q1_0, 145 F32) | **separate `output.weight`, Q1_0** (399 tensors: 254 Q1_0) |

The separate 8B classifier needed no engine change: `model/gguf.rs` already
reads `output.weight` into `Weights.classifier` when it exists, and the
logit path falls back to `token_embd` only when it is absent. The 8B greedy
run below is the check that it is actually used.

## Accuracy (wikitext-2 `wiki.test.raw`, `-c 512 --chunks 2`)

llama.cpp wrote the reference with `llama-perplexity --kl-divergence-base`;
its final estimates are 14.5341 ± 2.27514 (4B) and 13.1558 ± 2.01764 (8B).

| | 4B | 8B |
| --- | --- | --- |
| PPL (Aether) | 14.528180 ± 2.274972 | 13.172579 ± 2.018774 |
| PPL (base file) | 14.355021 | 13.046527 |
| Mean KLD | **0.000188** | **0.000192** |
| Same top token | 99.020 % | 98.824 % |
| 510 tokens scored | 203.4 s | 399.8 s |

Both are in the same range as B2's 1.7B (0.000264) and far below the
0.0020 that Qwen3 1.7B Q8_0 scored against llama.cpp. The larger models
have a lower perplexity on these two chunks (8B 13.17 against 4B 14.53),
as expected.

Raw: `b3-pc-ppl-4b-2026-11-22.txt`, `b3-pc-ppl-8b-2026-11-22.txt`.

## Greedy check

"The capital of France is", `--temp 0`, 24 tokens. Aether and
`llama-completion --no-conversation` print the same text on both files:
" Paris. Paris is the capital of France." repeated (the model's own
degenerate completion at this prompt, not an engine difference). This also
exercises the 8B's separate Q1_0 classifier.

kernel (the NEON `sdot`/`smmla` paths are aarch64-only); llama.cpp uses

## Memory

Peak RSS, `-c 512`: 1,302,240 kB (4B) and 1,827,864 kB (8B). The KV cache
is f32: 36 layers · 8 kv heads · 128 · 2 · 4 B · 512 ≈ 151 MB; the rest is
the mapped Q1_0 file plus the f32 activations and logits.
