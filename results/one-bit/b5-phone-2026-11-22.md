# B5 on the phone: Ternary Bonsai 1.7B Q2_0, correctness and memory

aether-infer `one-bit` B5 (`aether-b5`, built from `aa8ddf4` + the Q2_0
work), iQOO 13 (I2401), 6 threads on cores 2–7, against llama.cpp
`d02b4c0d6`. The vendor clock caps stayed at the second step
(2.40/2.44 GHz) for every run: the board cooled to 36.9 °C but the caps
did not return to 2.75/2.65 GHz in this session.

## Greedy

"The capital of France is", `--temp 0`, 16 tokens:

```
 Paris. The capital of France is Paris. The capital of France is Paris.
```

byte-identical to `llama-completion --no-conversation` on the same file,
and the 5 prompt ids match `llama-tokenize`.

## KL

wikitext-2, 2 chunks of 512, against the 4-chunk
`kl-base-llama-q2_0-wiki2.bin` written by `llama-perplexity
--kl-divergence-base`:

| | value |
| --- | --- |
| PPL(Q) | 15.69588 ± 2.501631 |
| PPL(base) | 15.616673 |
| PPL(Q)/PPL(base) | 1.005072 |
| Mean KLD | **0.000240** |
| Same top token | 99.216 % |

510 tokens in 9.5 s (not a cooled benchmark). The PC scalar path gave
0.000227 / 99.020 %; the difference is aarch64 float order.

## Memory (`-c 512`, one token)

| | Q1_0 | Q2_0 |
| --- | ---: | ---: |
| weights | 242.4 MB | 484.2 MB |
| peak RSS | 407,380 kB | 648,964 kB |

Q1_0's number is after its load-time repack into `Q1_0t`; Q2_0 has no
repack and stays in the mapped file.

## Kernel test on the phone

`kernels::tests::q2_0_matches_gguf_py` and
`kernels::tests::q1_0_matches_gguf_py` pass on the device (the real
aarch64 `dot1` / `dot4` / `mmla4` dispatch). One bug was caught there and
fixed before the model runs: the single-row `sdot` kernel subtracted
`Σq` from each of the four int32 lanes instead of from their horizontal
sum.
