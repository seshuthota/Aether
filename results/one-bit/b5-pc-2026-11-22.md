## Goldens

- `tools/gen_q2_0.py`: gguf-py's Q2_0 quantizer and dequantizer, Q8_0
  activations, a float64 product; six shapes with t = 1, 1, 3, 2, 5, 9.
  The first block's first byte is overwritten with codes 0, 1, 2, 3, so
  code 3 (`+2d`) is in every case.
- `tools/gen_bonsai_golden.sh`: `llama-completion` text and
  `llama-tokenize` ids for the greedy prompt.
